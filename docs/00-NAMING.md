# 00 — 名称与品牌

## 正式名称
**PhiTarget**

## 展示名称
**PhiTarget — Phigros Goal Score & Challenge Planner**  
中文副标题：**Phigros 目标分数与课题路线规划器**

## 命名理由
- `Phi` 让目标玩家联想到 Phigros 社区生态。
- `Target` 直接表达项目核心：给定目标分数、目标铭牌或目标等级和，反向求解。
- 相比 PhiCalculator/PhiCalc，不容易被误认为 RKS/B30 或普通数学计算器。
- 相比 PhiRoute，更突出“目标分数反推”这一独特功能；课题路线作为重要功能模块，而不是唯一功能。
- 名称短、易拼写，适合网页标题、仓库 README 和社区传播。

## 建议命名
- 产品：`PhiTarget`
- GitHub 仓库：`phigros-phitarget` 或 `PhiTarget`（创建前检查占用）
- 页面标题：`PhiTarget | Phigros Goal Score & Challenge Planner`
- 模块：`Target`、`Challenge`、`Rescue`、`Reachable`、`Profile`、`History`

## 候选名取舍
- `PhiCalculator`：描述准确但过泛、过长，容易与 RKS/普通计算器混淆。
- `PhiCalc`：短，但 PhiCalc 语义泛化，外部同名概率较高。
- `PhiRoute`：适合以课题路线为唯一主功能的产品；当前产品还包含单曲目标分和全可达分数分析。
- `PhiTarget`：覆盖目标分数、铭牌和规划，建议采用。

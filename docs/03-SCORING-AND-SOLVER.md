# 03 — 计分与求解器规范

> 实现前必须用当前游戏版本的真实结算截图校准公式与取整。公式、版本、取整策略应可配置。

## 变量
- N：总物量
- P/G/B/M：Perfect/Good/Bad/Miss 数
- C：Max Combo
- Z：B + M（仅用于推导）

始终检查 `P+G+B+M=N`，计数为非负整数。

## 普通模式
公开公式：

`Accuracy = (P + 0.65*G) / N`

`ComboRatio = C / N`

`RawScore = 900000*Accuracy + 100000*ComboRatio`

等价形式：

`RawScore = (900000*P + 585000*G + 100000*C) / N`

已知 N、P/G 和 C 即可计算普通模式分数；不需要完整谱面 JSON。若输入 G/B/M，可用 `P=N-G-B-M` 推导。

### FC 反推
FC：`B=0, M=0, P+G=N, C=N`。

`RawScore = 1000000 - 315000*G/N`

给定目标分，枚举整数 G（0..N），经过真实取整函数后寻找精确命中、最低达标方案、上下最近值。

### 固定 Max Combo
给定 N、C、G、Z：

`P=N-G-Z`

`RawScore = 900000 + (100000*C - 315000*G - 900000*Z)/N`

固定 C 时可反推 G/Z。检查 `G+Z<=N` 和音符判定资格。

### Max Combo 的边界
P/G/B/M 总数不能唯一确定 Max Combo，因为 Bad/Miss 的位置影响最长连续命中段。仅有总数时只能输出理论上下界或指定 C 的结果，不能声称精确恢复实际 Max Combo。

普通模式计分本身不需要 note 类型；验证哪些 G/B 组合符合谱面音符类型，才需要 Tap/Hold/Drag/Flick 统计；验证真实断连位置与 Max Combo，才需要谱面顺序或等价序列模型。

## 课题模式
课题模式不使用 combo score，只使用准确度部分：

`RawScore = 1000000 * (P + 0.65*G) / N`

不要把普通模式的 100000 combo 分加入课题模式。

课题模式判定窗口与普通模式不同，且不同 note 类型可获得的判定可能不同。公开资料列出课题模式 Good 仅适用于 Tap/Hold、Bad 仅适用于 Tap；Drag/Flick 的资格限制需按当前版本资料和真实测试确认。不要把所有 note 都假设为可出 Good/Bad。

若简化为 `Z=B+M` 且忽略 note 类型资格：

`RawScore = 1000000 - (350000*G + 1000000*Z)/N`

等价损失权重：

`L = 7*G + 20*Z`

这是数量模型，不代表该谱面实际可实现这些判定数。

## 取整
不要把浮点计算结果直接当作游戏显示分数。实现：
- 原始分数的精确有理数/整数分子分母；
- 独立 `roundGameScore(raw, formulaVersion)`；
- 真实成绩校验集；
- 对取整不确定的版本标记 `approximate`，不要伪装精确。

## 课题铭牌阈值
阈值必须放在版本化 `badge-rules.json`，不要散落在 UI 代码。当前公开资料常见区间：彩 3,000,000；金 2,940,000–2,999,999；橙 2,850,000–2,939,999；蓝 2,700,000–2,849,999；绿 2,460,000–2,699,999；低于 2,460,000 无铭牌。上线前再次核对目标游戏版本和实际铭牌规则。

## 可达分数
### 课题模式简化模型
对每个合法的 G、Z 计算整数损失 `L=7G+20Z`。有界范围内用 bitset/DP 去重。实际实现时再加判定资格上限，例如 Good 只能来自允许 Good 的 note 类型。

### 普通模式
- FC：只枚举 G，简单且精确。
- 固定 C：枚举 G/Z。
- C 未知：必须建模错误位置/最长连续命中段；只用 P/G/B/M 计数不足以精确枚举。

### 展示方式
不要默认渲染几万行。提供：
- 最低/最高分、不同分数数量；
- 100/500/1000/5000 分分桶；
- 目标附近 N 个结果；
- 每个分数 1–3 个代表性判定方案；
- CSV/JSON 导出。

当前网页已提供三种公式可达模型：普通模式不限制 FC，并把 `0 <= C <= N` 作为理论 Max Combo 范围；FC 模式枚举 `G=0..N`；固定 Max Combo 模式枚举 `G/Z`。普通模式使用 `K=63G+180Z-20C` 的区间合并计算分数集合，避免枚举三重组合；结果面板显示不同分数总数、最低/最高分、目标附近分数和 5,000 分分桶。所有结果仍标记为“公式可达”，不代表实际谱面顺序一定可实现。

## 求解器输出字段
`chartId, targetScore, achievedScore, delta, perfect, good, bad, miss, maxCombo, method, confidenceLevel, formulaVersion, chartVersion`。

# Phigros 录制界面观察

来源：用户提供的 `https://storage.to/W6g6yICYW`，下载到本地工作目录 `work/reference/phigros-ui-reference.mp4`（1920×862，60 fps，约 65.7 秒，140,374,023 字节）。该视频不进入 Git 和 Site 构建产物。

## 可复用的交互事实

- 章节选择是横向卡片带。卡片有斜切边、曲绘缩略图和半透明黑色遮罩；当前章节显示完整曲绘和 `PLAY` 操作。视频展示了 `Single`、`Legacy`、`Chapter 5` 到 `Chapter 9`、`Side story` 和多个联动精选集。
- 进入章节后，歌曲列表位于左侧，当前歌曲使用黑色斜切条和白色难度徽章突出；歌曲名、曲师和难度等级同时可见。列表可滚动。
- 顶部有返回、排序和设置入口。排序会切换歌曲列表内容和顺序，至少包含分数/随机/物量等入口，不能只提供一个静态曲名排序。
- 右侧主区域使用当前曲绘作为大图，并把曲绘的低对比模糊版本铺在整个背景；背景有细的多边形线条。
- 大图下方是 EZ/HD/IN/AT 难度切换条，选中的难度为红色斜切块，其余难度为白色斜切块；右侧显示分数、准确率和等级标志。
- 右下角是白色斜切的播放按钮。界面主要使用黑/灰/白色，红色用于 IN 选择，蓝色用于等级符号，避免大面积黄色和圆角卡片。

## 资源仓库核查

`7aGiven/Phigros_Resource` 的 `master` 只放提取工具，实际资源在独立分支：

| 分支 | 文件数 | 体积 | 用途 |
| --- | ---: | ---: | --- |
| `info` | 9 | 0.1 MiB | 曲名、曲师、曲绘画师、谱师、定数等 TSV |
| `illustration` | 330 | 514.2 MiB | 2048×1080 高清曲绘 |
| `illustrationLowRes` | 330 | 77.9 MiB | 列表/章节卡片缩略图 |
| `illustrationBlur` | 330 | 17.3 MiB | 背景模糊图 |
| `chart` | 1,057 | 2.5 GiB | 完整谱面 JSON，不在当前网页中打包 |
| `music` | 327 | 1.2 GiB | 音频，不在当前网页中打包 |

项目使用 `songId` 与资源文件名一一对应，通过 jsDelivr 远程地址按需加载三种曲绘尺寸；因此首屏只加载当前背景、主图和可见列表缩略图，不把 514 MiB 资源复制进 Site。

# 控分分析第一阶段

控分页面通过 Worker 按需读取选定难度的 Phigros 谱面 JSON，不下载整个谱面仓库。当前模型搜索以下策略：

1. 故意不输入一个 Tap 或 Hold；
2. 在该音符的 Miss 提交前继续命中后续音符；
3. 在指定物量之后完全松手；
4. 将所有实际命中的音符按 Perfect 计算，优先减少 Good。

`missCommitMs` 是校准参数，不等于已经确认的官方固定值。默认 180ms 只是当前用户给出的分析参数。模型目前还没有模拟 Drag/Flick 滑动路径、Hold 重新按回、判定线几何和同帧输入优先级，因此结果标记为 `timing-configured`，不能当作完整 Phigros 判定引擎的证明。

事件索引使用 `formatVersion: 3` 的谱面 JSON，音符类型按 1 Tap、2 Drag、3 Hold、4 Flick 解析。默认 32 个谱面时间单位为一个四分音符；该值可配置。完整官方行为校准后，应将录屏/实测成绩作为回归样本，而不是直接把 Phira 的常量视为官方真值。
